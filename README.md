# 🌐 Práctica HTML con GitHub Pages — 01

> Práctica de HTML + CSS con barra de navegación y tabla, con efecto glassmorphism.

## Qué contiene

- `index.html`: página con `header` + `nav.navegacion` (5 enlaces: Inicio, Tienda, Servicios, Nosotros, Contacto) y una `table` de 3 columnas (`col 1`, `col 2`, `col 3`) con 4 filas de ejemplo.
- `styles.css`: estilos reales del repo: menú con fondo semitransparente, `backdrop-filter: blur(10px)`, bordes redondeados, enlaces color `aliceblue` con `hover` rosa (`#ff9bf2`), tabla con `th` oscuro translúcido y `td` claro translúcido, y fondo fijo con imagen externa (`moewalls.com`, temática Bocchi the Rock).

## Estructura

```text
html-pages-lab-01/
├── README.md
├── index.html
└── styles.css
```

## Cómo verlo

- Doble clic en `index.html`, o
- Servidor local en la raíz:

```bash
npx live-server
```

- GitHub Pages (si está activado): `https://nahataen.github.io/html-pages-lab-01/`

## Notas

- Repo de práctica de clase: sin JavaScript ni build, solo HTML y CSS estáticos.
